# ROBLOX AI VIDEO FACTORY — Cloud Edition

This branch contains the Streamlit Community Cloud edition. The Windows edition remains on the `main` branch.

## Streamlit deployment

- Repository: `suboy-vn/roblox-ai-video-factory`
- Branch: `cloud-edition`
- Main file: `app.py`

See [README_CLOUD_VI.md](README_CLOUD_VI.md) for Vietnamese setup instructions, Secrets, Supabase setup and current limitations.

## Quick scope

Cloud supports AI-assisted story/character/world/director/sound planning, thumbnail layouts, YouTube SEO metadata, production job manifests, basic QC and batch queue exports. Roblox Studio, OBS and FFmpeg still run on the Windows workstation; automatic Windows Agent connectivity is a later integration.
